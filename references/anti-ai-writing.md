# 遣词与句式：先核对象，再核信息作用

版本：expression-v2-20261012。与 [禁用模式](banned-words.md)、[规则清单](表达规范库/manifest.json) 配合使用。本文取代旧版绝对禁词和机械句式清零要求；只提供抽象判断方法，不提供可换名套用的正文。

## 实际加载顺序

在 **Pass 2（轻量品控）** 或 **局部词句校对** 阶段，按需读取本文件、禁用模式和规则清单列出的 `wording.json`、`syntax.json`、`prohibited.json`，了解诊断与 `retain_when` 保留条件；本书另有适配文件时再加载本书文件。（注：Pass 1 作家态起草期沉浸于本书《本书文风锚点》与现场戏剧创作，不预载本诊断表打断语流。）

写后按需用同一份库只读扫描，返回章节、物理行列和规则 ID。随后回读命中处及同一事件；没有正则的语义规则仍须人工核对；带窄触发式的B类也须查事实来源，未命中不能作通过依据。词面只是定位线索，不能据此宣布原文有病或机械删句。

## 遣词用句的核对方法

| 规则 | 检查什么 | 保留条件与处理方向 |
|---|---|---|
| W01—W02 程度与动作副词 | 相邻强化是否区分了不同力度、阻力、速度或结果。 | 普通词可以用；有新作用就留，只撤回没有依据的重复强化。不能将所有动作统一改轻。 |
| W03 冷意与杀意 | 当前是触觉、环境、人物判断还是对同一态度反复盖章。 | 环境寒冷、明确杀意、人物有偏见的判断均可留；恢复本场真正的目的和态度。 |
| W04 修饰与量词搭配 | 修饰词有没有清楚的中心词，量词与对象是否相容。 | 先认清写的是人、声音、光、气血还是动作；搭配不当只修短语，正常量词不禁。 |
| W05、W10 比喻与尺度 | 不同喻体各提供什么感受，是否把普通节点持续写成巅峰。 | 有具体可感信息、角色特点或高潮依据就留；不以更换同义大词代替修正。 |
| W06—W07 声线与表情 | 修饰是否符合本次台词、身份关系和下一步行动。 | 有辨识作用就留；若把交涉改成求饶、戏谑改成嗜血，优先恢复人物态度。 |
| W08 感受主体 | 谁在感到害怕、难堪或压迫，依据来自哪里。 | 明确角色的主观话语可留；叙述者不可无依据替所有人统一感受。 |
| W09 能力与程度结论 | 修辞是否暗中补写药效、材质、免疫、装配或成长结论。 | 已确认事实可以写，未确认的效果不能靠形容词升级为事实；感官效果、器物材质、药效与身体变化均须人工查来源，不能只依赖窄触发式。 |

正向选词、解释颗粒度与句法腔调遵循本书《本书文风锚点》及角色身份，不受封闭白名单限制；诊断库中的触发词仅作审校复核定位线索，不自动判为病句。

## 句子格式与段落的核对方法

| 规则 | 检查什么 | 保留条件与处理方向 |
|---|---|---|
| S01—S02 结果多次认证 | 动作、破坏、旁观、独段计数是否反复宣布同一结果。 | 每层增加新结果、人物认识或实际后果时可留；胜负已清楚后推进后果。 |
| S03 对白前姿态套餐 | 每句前是否固定安排嘴角、眼神、声音和冷笑。 | 确有态度变化或动作阻碍时可留；不要求每句对白都有姿态。 |
| S04 比较、否定与递进 | 是纠正身份、解释方案，还是重复评级。 | 必要的纠正、对照、人物辩解均保留；“不是……而是……”不是禁句式。 |
| S05 拟声与释义 | 声响、动词、比喻是不是连续重演一个声音。 | 不同动作需要不同声响时可留；拟声、感叹号本身不禁。 |
| S06—S07 心理与视角 | 情绪是否让人物转念，群体反应是否符合各人的信息和利益。 | 直接心理、强情绪和有依据的群体反应均可留；不把所有心理替换成发抖握拳。 |
| S08 长句与逗号 | 能否一遍辨认主体、动作顺序与修饰对象。 | 主体清楚、意思连贯的长句保留；只在歧义或对象错配处调整。 |
| S09 停顿与悬置 | 破折号、省略号和最后一刻是否重复制造同一种延迟。 | 真正的打断、转念与紧急节点保留，不机械换成句号。 |
| S10 系统界面 | 信息层是否清楚，括号是否嵌套混乱或反复认证同一收益。 | 合法面板、记录、选项及本书叙述形式保留，不按括号数量删改。 |

按完整意思、接话、转念、动作结果和叙事层变化断段。不要统一一句一段，也不要为了回避某种排版而强行拼接。句长、标点、连排短对白、破折号、感叹号、段落长度和命中次数都没有任何配额或禁令，全部服从戏剧张力与可读性。

## 修改与记录

每个待修点记录：输入哈希、章节和行号、规则 ID、同一事件依据、该处作用、保留或最小修正的理由。涉及新增能力、身份或剧情的疑点另列，不借词句校对直接改事实。只优化技能时，只交付这些规则与证据，不改正文。

参考作品的原句和短引用只留在项目离线校验记录；生成阶段不加载这份证据原句，也不把它们变成替换句库。后续新稿继续以实际事件和阅读反馈复核，不以命中清零作为写好标准。

## 本轮补强：先核输入，再核表达作用

准备场景摘要时，将会影响行动的能力、身份、消息来源和时间与有效来源逐项对上。能力要保留对象、条件、范围、代价及当前是否启用；记住资料不等于掌握，能学会不等于已经学会，局部数量不等于全局总量。正式规则与章纲冲突时登记两处来源，区分作者明确改设与摘要误读；在解决前不自行折中造新规则。不要将AI稿或上次检索摘要中的新增信息默认升格为事实。凭证只证明检索发生，不证明输入正确。

写前用完整语言说明本场靠什么改变局面：验证能力、对话改变方案、证据引出调查，或角色在允许节点作选择。沿用有效规划的因果；不把这些作用换成更响的光效、所有人赞服或无依据的巧合。写后回到实际段落核验：条件真的起了作用吗，配角的应答改变了哪一步，推测何时获得了新证据？这不是必须每章齐备的固定流程。

判断迭代效果时，把旧规则版本固定后再比较；扩大新库后增加的命中不能算稿件退步。按相同口径给出每万有效汉字频次，另读对应事件。冷色词减少而雷击、神罚、绝对化和多层震惊增加，只能说明措辞发生迁移。保留下来的旧优点不记成新增进步；最终好坏永远以读感、故事因果和事实自洽为准。
