# 每本新书建立独立技能包与文风锚点引导

用户授权创建新书即自动执行以下初始化，无需事先询问“是否建立技能”；但在**初始化落盘完成后，必须依据技能立即发出【文风锚点】询问回复**。先确认书名与项目根目录，严禁继承上一部书的人物、设定、资源账或专属口头禅。

## 一、本书初始化目录与文件清单

1. 在新书根目录创建标准创作文件夹（若尚不存在）：`正文/`、`规划/`（或 `大纲/`，遵从用户习惯）、`设定/`、`写作校验/`，并在根目录建立本书 `AGENTS.md`，指向本书本地 `skills/novel-workflow/SKILL.md`。
2. 在新书根目录创建完整的 `skills/novel-workflow/` 独立技能包（复制实际文件而非仅放跳转链接；各书专属配置仅供对应项目使用；若本地技能已存在则增量合并，严禁整包覆盖作者已有内容）：
   - `SKILL.md`（移除其他书的硬编码分支，路由指向本书 `references/本书配置.md` 与 `references/本书文风锚点.md`）
   - `agents/openai.yaml`
   - `references/本书配置.md`（填写已知书名、题材、目标平台、视角、单章字数底线默认不低于 1700 有效汉字等，未知项标待定）
   - `references/本书文风锚点.md`（从公共模板复制初始 `status: pending` 槽位）
   - `references/文风锚点与自动入库.md`
   - `references/实战技法速查目录.md`
   - `references/小说叙事底层.md`（番茄重生/穿书系统爽文同步复制 `番茄重生系统文开篇与结构.md` 并按本书题材微调标题与适用说明）
   - `references/de-AI-writing.md`、`references/章纲模板.md`
   - `references/good-writing.md`、`references/口吻、情绪与叙事节奏.md`
   - `references/情绪保留式去AI.md`、`references/anti-ai-writing.md`、`references/banned-words.md`、`references/表达规范库/`（含 `manifest.json`、`wording.json`、`syntax.json`、`prohibited.json`、`README.md`）
   - `references/改稿经验.md`、`references/同步流程.md`
   - `scripts/`：复制 `analyze_style_sample.py`、`check_chapter_length.py`、`check-ai-patterns.js`、`compare_drafts.py`、`quick_count.py`

> **不复制项**：不再复制 `technique-evidence.ps1`、`reference-evidence.ps1`、`reference.ps1`、`朱雀验收.md`、`zhuque_check.py`，也不绑定共享 SQLite 的 512 维向量检索、331 词 `approved` 词库校验或朱雀检测。不从其他书复制 `本书适配.json` 或离线原句证据。

## 二、初始化完成后的强制动作：询问设置【文风锚点】

完成上述目录和本地技能初始化后：
1. **未获明确跳过指令前，不得擅自直接生成大纲或正文。**
2. **立即读取并执行 [文风锚点与自动入库](文风锚点与自动入库.md) 第一节**，向用户输出技能规定的**标准自动询问回复**，请用户选择：
   - 上传/粘贴自己写的样章或满意片段（原味清洗拆解入库）；
   - 上传/发送喜欢的参考小说文件或片段（提取声学与叙事指纹，剥离原书专名与原句后脱敏重构入库）；
   - 由 Agent 现场生成 500 字 A/B 双腔调试镜小样供挑选定调；
   - 或暂不设置先按题材默认基调推进。
3. **收到用户上传的小说或自写样例后**：自动调用本地 `scripts/analyze_style_sample.py` 扫描声学特征，并按 [文风锚点与自动入库](文风锚点与自动入库.md) 第二节四步 SOP 自动拆解填充至本书 `skills/novel-workflow/references/本书文风锚点.md`，更新 `本书配置.md` 后向用户汇报核心文风指纹。

## 三、初始化自检与后续维护

- **初始化自检**：确认本书 `AGENTS.md` 与本地 `SKILL.md` 相对链接全部有效、`表达规范库` JSON 可被 `check-ai-patterns.js` 正常解析、`analyze_style_sample.py` 与 `check_chapter_length.py` 可正常调用，且无任何其他小说的人名与设定残留。
- **后续维护**：本作实测有效的写作与改稿经验写入本地 `references/改稿经验.md`；当作者精修某章正文并认可其语感时，优先将最新定稿好段迭代更新至本地 `references/本书文风锚点.md`。公共模板的后续更新不自动覆盖已专属化的旧书。
