# 禁用库：核实后禁止的错误模式

版本：expression-v2-20261012。实际规则在 [prohibited.json](表达规范库/prohibited.json)，由 [manifest.json](表达规范库/manifest.json) 加载。旧版把普通词、心理、否定句、比喻和标点一律判错的要求全部撤销。本库规范表达与事实，不提供作者身份检测。

## 生成与改稿必须避免

| ID | 核实后禁止的模式 | 判定与修正 |
|---|---|---|
| B01 | 把未发生的台词、所见或经历写成既有证据。 | 回查谁在何时实际说过或见过；没有来源就不能作确证性引用。合理回忆和已发生的台词可以写。 |
| B02 | 用修饰追加未确认的能力、药效、材质、规则或成长结果。 | 逐项找有效正文、作者要求或正式规则的来源；不能用强度词抹掉原有限制。已有能力正常发挥可以写。 |
| B03 | 没有新信息却连续宣布同一结果。 | 按同一动作核对各层贡献；有新的认识、代价、关系或局势变化就不是此项。 |
| B04 | 未验证便把线索拼接为定论，把局部情报扩为全局规模、期限、动机，或代所有人统一感受。 | 回查确证来源与角色知情；合理推测、夸口、不可靠观点仍可写，不能由旁白认证为已证实。 |
| B05 | 没有因果就重置已发生的身份、待遇、伤势、物品或关系状态。 | 连读进入与离开场景的状态；有明确回忆标记、真实损失或新事件时可变化。 |
| B06 | 已确认的中心词、承载对象与量词错配。 | 只修错误搭配，不把整个词设为禁词；角色有意的特殊表达结合口吻核实。 |
| B07 | 复制参考原句、显著模板、独特意象或世界观用于生成。 | 只迁移抽象组织方法；来源短引留在离线证据文件。此项是来源边界，不暗示已发现抄用。 |

扫描器对 B 类也只报候选，自动结果没有证明事实错误的能力。人工确认条件成立后，在已授权范围修复；只获准词句校对而涉及剧情、能力、身份变动时，登记结构或设定疑点，不越权改写。

## 需要结合上下文检查的表达

wording.json 的 W01—W10 和 syntax.json 的 S01—S10 是复核线索。强化副词、冷色神态、声线比喻、嘴角、瞳孔、量词、比较和停顿，都须结合当前人物、事件与相邻段落判断。原本也有正常使用的反例，不能把风格差异直接当作错误。

下列情况必须保留正常用法：有具体内容的心理；纠正身份或说明选择的否定句；表达打断或转念的标点；有作用的比喻、长句、拟声和强情绪。不得把词换成另一个同义大词后宣称问题解决。

manifest.json 的 explicit_literal_bans 当前为空，表示本轮没有把任何普通词设为无条件字面禁词。若作者以后明确指定字面禁词，必须另记适用书目、范围和授权来源，并同步实际扫描逻辑，不能只往说明中加一行。

## 执行约定

写前读取全部规则及其保留条件，写后用相同版本库扫描，再核对未自动覆盖的语义项。全部B类列入 semantic_checks，带检测式也仍须全文查来源。没有命中不表示内容合格；命中也不直接阻止正常表达。默认只读扫描成功退出码为0，配置错误为2；显式 --fail-on=all 只表示调用者要求把复核候选作为流程提醒，不代表文字已被判错。

不用固定次数、段长或分数替代判断，不自动改标点、不自动写回、不调用检测服务。项目独有的模拟、装配、自称、能力边界与体系核对留在项目适配文件，不扩展成其他小说的硬规则。
