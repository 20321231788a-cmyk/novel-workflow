# 文风锚点：新建询问自动回复与样例自动拆分入库

文风（Voice）不存在于死板的数字指标里，而存在于句式呼吸、视角贴合度、信息解释颗粒度与人物活人感中。本模块规定**新建小说时的自动询问回复机制**，以及**用户上传参考小说或自写样例后的自动拆解入库流程**。

---

## 一、新建小说时的标准自动回复（强制触发）

当用户要求**新建一本小说 / 开新书 / 初始化新书目录**时，Agent 先按 [新书专属化](新书专属化.md) 完成项目目录与本书独立 `skills/novel-workflow/` 的创建，随后**必须暂停自动生成大纲或正文，依据本技能向用户发送以下标准自动询问回复**（将 `{书名}` 替换为当前书名）：

```markdown
新书《{书名}》项目目录与专属创作技能已初始化完成。

在正式规划大纲或起草正文前，**是否需要为本书设置专属【文风锚点】？**（设置后可让 AI 稳定对齐你的句式呼吸、叙述人设、情绪烈度与解释颗粒度）：

1. **上传/发送你自己写的样章或满意片段**（强烈推荐，500—3000 字即可）：我将仅修正错漏字、保留你的原汁原味语感，自动拆解提取为本书《黄金语感样段》与《叙述者灵魂》入库。
2. **上传/发送你喜欢的参考小说文件或片段**：我将观察其句长节奏、旁白腔调、对白嵌合度与爽点解释方式，**彻底剥离原书人名、设定、剧情与独特比喻**，结合本书设定脱敏重构为本书专属文风锚点入库（零抄袭与串设定风险）。
3. **由我现场生成 A/B 两版 500 字试镜小样**：若你手头暂无样例，我可按本书题材生成两种不同腔调的试镜片段，你挑中或顺手改几句后直接封存入库。
4. **暂不设置，直接推进**：先按本书题材默认基调开始规划，后续随时可补充样章入库。

请直接上传文件、粘贴样例文字，或告诉我你的选择。
```

> **交互补充**：若用户选 `3`，立即围绕本书第一章核心冲突生成两版各约 500 字、腔调有显著区分（如“热血直给解释型” vs “冷峻腹黑算账型”）的试镜片段供用户拍板；若用户选 `4`，将本地 `本书文风锚点.md` 标为 `status: skipped_default` 并继续执行用户的规划或写作任务。

## 二、用户上传小说或自写样例后的自动拆分入库流程

一旦用户上传了小说文件（TXT / MD）或在对话中粘贴了自写样例，Agent **无需用户手动切分**，必须自动执行以下四步入库流水线：

### 第 1 步：落盘原始样本并辅助观察节奏特征

1. 若用户直接在对话框粘贴文本，先将其原样保存至当前书项目的 `写作校验/文风样本/原始输入样本.md`（若用户上传了文件路径则直接读取该路径，不移动用户原文件）。
2. 可运行文风样本分析脚本辅助观察节奏分布（超大参考小说默认截取前 40,000 字代表性区间）：
   ```powershell
   python -X utf8 "<本书技能目录>/scripts/analyze_style_sample.py" "<样本路径>" --output "<本书根目录>/写作校验/文风样本/声学特征报告.json"
   ```
3. **重要原则（去数值配额化）**：脚本输出的平均段长、句长分布与对白占比**仅用于定性感知样本的快慢呼吸与对白节奏**，**严禁把这些统计数字（如“短句占比 48%—55%”“每千字反问 22—26 个”）写成正文的硬性配额**。

### 第 2 步：按来源属性执行“双通道安全分流”（严守原创边界）

必须先确认样本是**【通道 A：作者自写原创稿】**还是**【通道 B：外部参考小说/他人作品】**：

- **通道 A（作者本人写的本书样章或过往自写稿）**：
  - **原味保留原则**：100% 保留作者的句式节奏、直白解释习惯、情绪爆发烈度与标点断行习惯；**仅修正明显的错别字、重字、漏字硬伤**，绝不把作者鲜活的口语“润色”成四平八稳的公文腔。
  - 若是作者过往其他自写书的稿件，仅将其中涉及旧书的人名、专名替换为当前新书对应设定词，保留原句法骨架。
- **通道 B（外部参考小说）**：
  - **脱敏重构铁律**：**严禁把外部参考小说的原句、人物、世界观专名、具体桥段或独特比喻直接写入 `本书文风锚点.md`！**
  - Agent 仅提取参考样本的**节奏感、旁白贴近度（自由间接引语方式）、信息解释颗粒度、动作与对白嵌合结构**，然后**以当前新书已确认的主角身份、金手指/设定与开篇处境为载体，现场仿照该神韵全新改写生成 2—3 段《本书定制黄金语感样段》**。
  - 入库前自检：新生成的定制样段不得与参考小说存在连续 10 字以上的原文重合，不得残留任何参考书专名。

### 第 3 步：拆分为精简核心模块写入本地 `references/本书文风锚点.md`

将拆解结果覆写存入当前书的 `skills/novel-workflow/references/本书文风锚点.md`，避免冗长教条和机械配额：

1. **节奏与张力定性感知（无机械数字配额）**：
   - 定性说明句式呼吸（如：日常吐槽轻快利落，算账或压迫立威时收紧拉长）、段落聚散习惯（短句独行重音与紧凑叙事段随情绪自由切换）、对白与叙述咬合方式及解释直给度。
   - **彻底解放排版与标点**：不再限制单句空行、连续短对白、破折号、问叹号等表现手段。
2. **叙述者灵魂与风味示例**：
   - **旁白定位**：明确第三人称旁白如何充当主角“嘴替”（价值观、看人视角与情绪温度）。
   - **风味词汇示例（非复读清单）**：列举若干贴合人物口吻的口语连接与吐槽风味示例，**明确要求随着新剧情不断即兴造新梗，严禁每章机械复读同一批固定口癖**。
   - **核心感官锚点与出戏禁区**：写清本书抓哪类细节最有画面感，以及绝对不能串味的腔调（如禁止科研工程汇报腔、禁止违背设定的苦情腔）。
3. **精选《黄金语感样段》（2—3 段，重点保留最对味的原味切面）**：
   - 精选最具代表性的高张力切面（如【冲突爆发与反击】、【内心盘算与主观态度】、【设定/胜负逻辑直给】），作为 Pass 1 起草的语感校准器。
4. **可选《Before / After 对照》（2—3 组，按需配置）**：
   - 仅保留最关键的正反照妖镜对照（如去工程汇报腔、去二手梗概流水账、对齐本书核心口吻），不强行凑齐冗余条数。

### 第 4 步：更新配置状态并向作者确认

1. 将 `本书文风锚点.md` 顶部的 `status` 设为 `configured`，注明样本来源类型与入库时间；同步在本地 `references/本书配置.md` 登记文风基调摘要。
2. 向作者简要汇报已提取的**核心文风特征与样段清单**，确认无误后即可在后续章节起草中加载生效。

## 三、日常创作中的调用与保护规则

1. **Pass 1（作家态起草）加载**：每次起草、续写或重写本书正文前，读取本书 `references/本书文风锚点.md` 找准声线与语气重心，随后放手依剧情现场发挥，把风味写成活戏而不是模板复制。
2. **Pass 2（轻量品控）禁止毁文风**：在做字数核对与局部词句校对时，必须保护文风锚点确立的**解释直给度、人物口吻、标点鼓点与现场戏剧感**，不得削弱情绪烈度或把鲜活交锋压成大纲流水账。
3. **动态迭代**：创作过程中，每当作者亲手精修了某一章或盛赞某一段“写得最对味”，可随时将该最新定稿片段替换补充进《黄金语感样段》，让越往后写的章节越贴合作者手笔。
