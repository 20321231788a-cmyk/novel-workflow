# 正文创作：Pass 1 作家态沉浸起草 + Pass 2 轻量品控

## 局部词句校对的边界（非创作模式）

当作者只要求**改用词、修句式**时，不进入重写流程：以指定原稿为底局部修正语病、搭配不当、指代不清与歧义；保留原有的台词态度、直接心理、修辞、感叹与段落呼吸，不以“更短、更克制、更像流程说明”为改好标准；发现剧情或设定疑点单独列出，不越权改写情节。

## Pass 1：作家态沉浸起草（中度放权 · 把戏演活）

**加载原则**：起草阶段专注故事张力与本书腔调，**只读取**本书 `本书配置.md`、`本书文风锚点.md`、本章有效章纲、上一章最新末尾 100 字及本章涉及的设定/资源账（遇复杂多层叙事或细腻节奏时按需翻阅 [口吻、情绪与叙事节奏](口吻、情绪与叙事节奏.md)）。**不跑向量检索、不查批准词库白名单、不背诵任何防检测条规，也不强制写前阅读历史改稿记录。**

### 1. 动笔前先对齐《本书文风锚点》
- 阅读本书 `references/本书文风锚点.md` 中的**《黄金语感样段》**与叙述者灵魂（若本书尚未配置文风锚点，按 `本书配置.md` 的题材基调与叙述人设行文）。
- 锁定**旁白人设（自由间接引语）**：第三人称旁白不是冷冰冰的监控探头，而是贴着主角脑回路的“嘴替”——观察对手神态、衡量局势筹码、解释能力利害时，自然带上主角的身份视角、算盘与情绪温度。
- **防复读提示**：文风锚点里的口癖与示例仅用于找准“味道”，禁止每章机械重复同一批口头禅或动作套路，鼓励随着剧情推进即兴生发新包袱与新互动。

### 2. 中度放权与临场发挥权
- **章纲给方向，现场给灵魂**：章纲只约束“出发点、必须发生的关键事实、底牌边界与终点落点”。在抵达终点之前，允许你在写作现场即兴碰撞出更妙的对白交锋、更损的反套路算计、更炸的情绪爆点或更自然的小转折，不必把写正文做成“按图填色”。
- **彻底解放标点、断行与对白张力**：连排短促对白、独立成行的重音短句、破折号（`——`）、问叹号（`？！`）、省略号、系统短框等，全部服从**戏剧节奏与题材鼓点**。该连珠炮打脸时就连续短对白拉满火药味，该铺陈蓄势时就用紧凑自然段推进，不存在任何检测器避坑限制。
- **题材美学最高准绳**：若本书定位为高浓度快节奏爽文、沙雕修仙或漫剧短剧，优先拉满本书《本书配置》与《本书文风锚点》追求的夸张反差、情绪轰炸与爽感密度，不被传统写实风格的克制建议磨平棱角。

### 3. 把局面演成“有解释、有细节、有交锋”的现场好戏
- **该讲透的逻辑痛快讲透**：首次阅读正文的人必须不看大纲就能看懂主角为何出手、对手依仗什么、主角抓住了哪处短板或信息差破局、赢下了什么实际好处。商业爽文不必故作高深地过度克制，面板克制、战术算计、前世血仇与实力反差可以直接掰开讲清，再用干脆的动作和结果兑现。
- **严防“二手梗概化转述”——用半现场写法保戏剧张力**：
  - ❌ **错误（梗概流水账）**：把核心冲突全压成间接转述（如*“室友跑过来挡在中间给他女友洗白，说什么走近点只是考验他，女友也嫌他磨蹭伸手要U盘”*），会让正文退化成大纲扩写，丧失刺痛感与爽感。
  - ✅ **正确（现场与半现场张力）**：压缩无关痛痒的寒暄，在冲突爆点处放出最具杀伤力的原话引号、让人有画面感的越界微动作和主角即时内心算盘，紧接干脆利落的破局动作。
- **人物直接心理与身体反应各司其职**：允许直接写出主角的偏爱、怒火、算计、得意或吐槽，只要符合人设并推动选择；若心理已经把算盘敲得明明白白，就不必机械套配“握紧双拳、眼眶通红、喉头发紧”。
- **能力与物品严守账本状态**：已拥有不等于本场全开，记住原著/背景不等于手握现世证据；切回现实时先接回站位与手头动作，不无故重置已发生的关系和待遇。
- **无缝承接上章**：动笔前核对上一章末尾 100 字，从新动作、直接回应或既定后果往下推，绝不把上一章演完的结尾换词重演一遍。

### 4. 正文章长约束
- 默认单章有效正文汉字 **不低于 1700 字（不设硬上限，依剧情高潮与戏剧节奏自然收尾）**；本书 `本书配置.md` 另有更高下限或用户有最新要求时优先遵照。
- 统计口径：仅计正文汉字，不计章标题、标点、空白、阿拉伯数字、英文字母与文末创作说明（正常对白与正文内的面板/记录计入）。

## Pass 2：轻量品控（守住故事与事实，不毁灵气）

初稿落盘后，执行轻量品控即可，**严禁为了机械达标而把初稿的灵气和情绪洗成白开水**：

### 第 1 步：首次阅读故事与事实自检（最高优先）
只读正文（遮住大纲）自问五句话：主角眼下争什么？对手怎么挡？主角凭什么破局？打完/做完实际改变了什么？读者下一章具体等什么？同时核对时间、空间、能力边界、人物知情与物品账本是否一致。若前因缺失就补清因果，若事实打架就定点修正。

### 第 2 步：自动化字数底线核验
运行：
```powershell
python -X utf8 "<技能目录>/scripts/check_chapter_length.py" --min-han 1700 --output "<本书校验目录>/字数报告.json" "<正文路径>"
```
字数不足 1700 时，从核心冲突的动作交锋或人物回应自然展开，不用无关日常或重复威力描写硬凑字数；单章写得顺畅饱满超出两千多字时，只要节奏紧凑不注水，无需强行砍短。

### 第 3 步：按需表达规范只读扫描
如需要排查语病与事实越界，运行：
```powershell
node "<技能目录>/scripts/check-ai-patterns.js" --check --json --library-dir "<技能目录>/references/表达规范库" --output "<本书校验目录>/表达扫描.json" "<正文路径>"
```
（有本书适配 JSON 时追加 `--profile`）。结合 [遣词与句式方法](anti-ai-writing.md) 与 [禁用模式](banned-words.md) 回读命中行及语义项，重点清查：**把未发生的事写成既有证据（B01）、靠形容词暗中升级未确认能力/药效（B02）、无新信息的同义复播（S01/B03）**。正常的直接心理、比喻、否定句、连排对白、感叹与强情绪一律保留。

### 第 4 步：朱雀检测停用声明
工作区内已彻底删除朱雀 CLI 并全面停用朱雀检测（CLI 与 MCP），后续创作与改稿均不再调用朱雀检测，也不再执行任何围绕检测器规则的切片或标点改稿。
